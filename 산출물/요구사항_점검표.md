- 점검 방법 : 실제 서버를 실행해 `하이닉스` 를 검색하고(토스증권 실시간 크롤링 + 실제 GMS API), 각 요구사항의 화면을 캡처

  · UI 개편(채움) 후 화면 캡처 재촬영 : F603·F611 은 실제 크롤링으로 다시 촬영, F601·F605·F607·F610·최근 분석 기록은 레코드 #3 을 새 화면으로 촬영
